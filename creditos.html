Sobre o projeto

Este site é um projeto educacional de e-commerce fictício. Nenhuma venda real é processada. Todos os dados ficam armazenados apenas no navegador do usuário (localStorage/sessionStorage) e são perdidos ao limpar os dados do site.

Desenvolvido como atividade acadêmica demonstrando competências em HTML5 semântico, CSS3 com variáveis customizadas, JavaScript vanilla ES6+, design de interfaces modernas, boas práticas de acessibilidade e experiência do usuário.
